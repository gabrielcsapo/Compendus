Get started

Your library, on your own terms.

Compendus is a self-hosted home for ebooks, audiobooks, and comics. This guide takes you from an empty server to your first synced reading session.

Before you begin
Install Node.js 22 and pnpm. For the native app, you’ll also need Xcode 16 or later.

Install the server

Clone the repository, install dependencies, and start Compendus in development mode. 

git clone https://github.com/gabrielcsapo/compendus.git
cd compendus
pnpm install
pnpm dev

Add your first book

Open http://localhost:5173, drop an EPUB, PDF, comic archive, or audiobook anywhere in the library, and Compendus will prepare its metadata and reading assets.

Continue on web

Open the book and your reading position saves automatically.

Connect iOS

Enter the server address once, choose a profile, and download any title.

Where to go next

Read about the system architecture, connect the iOS app, or explore the API.

Concepts

One library, three layers.

Compendus separates durable source files, prepared reading assets, and per-reader state so each can evolve safely.

Sources

The files you own

Original ebooks, comics, and audio remain the source of truth.

Reading layer

Prepared for every screen

Normalized content, covers, transcripts, and search indexes.

Reader state

Personal and portable

Progress, highlights, downloads, sessions, and profiles.

Discovery

Built from your library

Collections, semantic links, and Wander stay grounded in books you own.

Request flow

source file → ingestion → prepared asset → reader
                                  ↘ search + wander

Principles

The server owns canonical metadata. Devices own offline copies. Sync exchanges the smallest durable state needed to preserve a reader’s place.

Native app

Read offline on iPhone and iPad.

The native app downloads books from your Compendus server and keeps progress, highlights, and audio position in sync.

Connect to a server

  1. Open Compendus on iOS.
  2. Enter the server’s local or public URL.
  3. Select your reader profile.
  4. Download a title from Library.
Local networks
iOS may ask for Local Network access the first time you connect. Allow it when your server is on the same Wi-Fi network.

Offline reading

Downloaded books appear in Library alongside cloud titles. A small download state replaces a separate “On Device” product hierarchy.

Audio and read-along

Audiobooks, neural text-to-speech, transcripts, and word tracking share one player surface and one saved position.

Reference · v1

A small API for a personal library.

Use the REST API to browse, upload, prepare, and read library content. Local deployments use /api as the base URL.

Books

Reference

Bring the books you already have.

Compendus normalizes common ebook, comic, and audio formats into a consistent reading experience without discarding the original files.

Ebooks

EPUB · PDF · MOBI · AZW3

Reflowable text, fixed pages, search, highlights, and reading progress.

Comics

CBZ · CBR

Page spreads, thumbnails, panel-aware navigation, and offline extraction.

Audiobooks

M4B · M4A · MP3

Chapters, sleep timer, synced position, transcripts, and CarPlay.

Prepared content

CCD

Compendus’ normalized content format for predictable reading across devices.

Processing states

New files move through uploaded, preparing, ready, or needs attention. Readers can continue using the rest of the library while preparation runs.

Guide

Listening, reading aloud, and following along.

Compendus treats narration as part of reading—not as a disconnected media feature.

Audiobooks

Chapter metadata and playback position sync between the web player and native iOS app. Downloaded audio remains available offline.

Transcription

Whisper creates searchable transcripts with timestamps. Run it on the server or on-device, depending on your privacy and performance needs.

Text to speech

Web browsers can read reflowable books aloud. iOS can use neural voices with sentence and word-level tracking.

Design principle
The same progress rail marks where you are whether you read, listen, or switch between the two.
